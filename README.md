# 🎨 JS UI Components Hub

A modern and beginner-friendly collection of reusable JavaScript UI components to help frontend developers build faster and cleaner UIs.

## ✨ Components Included
- Buttons & Hover Effects
- Modal Boxes
- Progress Bars
- Search Filters
- Image Sliders
- Form Validation
- Dark / Light Theme Toggle

## 🚀 How to Use
1. Click the **Fork** button on the top right
2. Open your forked repo
3. Edit `index.html` and start customizing

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)
